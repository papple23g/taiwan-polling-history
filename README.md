# 選情劉伯溫

台灣歷史民調資料與誤差分析。分別收錄已核實的原始民調與尚待核對的歷史來源線索；不提供未來預測、勝率或整體機構可信度排名。

[GitHub 原始碼](https://github.com/papple23g/taiwan-polling-history) · [問題回報與資料更正](https://github.com/papple23g/taiwan-polling-history/issues)

目前資料版本 `1.3.0+20261018`：14 場官方結果、789 筆歷史民調（360 筆一手核實、429 筆待核對），另存 365 筆候選情境、22 筆待釐清紀錄。每筆附公開來源，保留未知欄位、來源衝突及無法讀取原文的限制；這不是所有歷屆選舉民調的完整資料庫。資料版本與更新日期取自資料集，不代表網站程式的更新日期。

## 方法

主要分數為平均絕對誤差（MAE），單位百分點，採同一候選人集合正規化後的平均絕對差。來源核實與算術分開：可對齊候選組合、支持度與官方票數時，尚未符合正式資格者仍保留試算數值；有數值不代表來源已完成核實。無法裁定輸入、候選組合不符或缺值則保留無法計算原因。主表預設按數值由低到高，缺值置後；完整查核狀態與正式資格放在紀錄詳情的來源／備註，不在主表拆欄。民調與實際結果使用相同候選人集合，各自正規化至合計 100%，再平均候選人絕對差。切換原始比例不改變分數；缺值不當零、未表態不分配。回答合計異常保留提示及試算，正式資格仍受一致性門檻限制。勾選「選前 30 天」時，調查結束日限於投票日前 1 至 30 天，第 30 天包含在內。跨場自動納入全部機構品牌，同名與明列別名合併，每個品牌每場取一筆符合正式條件的民調；明示且核實的封關民調優先，否則使用本資料集中最後合格且可核實的版本，原始機構 ID、執行者及來源保留。逐場分數有資料即列出，跨場平均 MAE 只採全部品牌的共同選舉集合，至少三場才顯示。

MAE 是歷史民調與事後選舉結果的描述性差異，不是民調的抽樣誤差。調查時間、對象、方式及選情變化均會影響比較，不能以單次結果推斷機構整體可信度或未來表現；微小差距可能受四捨五入影響，本站不宣稱差距具統計顯著性。

單場預設「封關民調」，每個原始調查單位顯示最新一筆；切換「歷史民調」可查看各波次。選前 30 天預設不勾選。民調整列可點選查看詳情，來源連結獨立開啟。三角圖與散點圖的淡色區域可 hover 查看候選人勝選區與邊框，圓點提示保留原有數值。來源索引涵蓋中英文維基歷史表格，並補查 TVBS、ETtoday、美麗島、台灣民意基金會等原發布者、新聞全文及搜尋摘要；各類證據分開記錄。未知調查結束日不以索引日期代填；取消30天篩選可查閱全部歷史線索。候選情境及數值衝突可從表格下方的來源清單查看。2024 年 1 月 3 日起禁止公布民調的封關後數據不納入這批選前公開紀錄。2018 臺北採驗票後更正結果；2022 桃園採正式整數票數。完整欄位見 DATA-CONTRACT.md，證據與方法見 public/data/verified-source.json。來源輸入保存在 source-data/historical-poll-index.json，可由 import-historical-polls.mjs 冪等匯入，再從 source-data/parts 重組並由 import-verified-data.mjs 轉接與重算。

兩人散點圖與三人三角圖在圖上提示「滾輪放大／縮小、拖曳平移」，雙擊還原；三角圖最多放大 100 倍。三角端點與兩人圖左右兩側顯示 36px 真實候選人照片、完整姓名與該次選舉的政黨色邊框。同一人跨選舉共用本地照片；26 位候選人的原始出處、作者與授權可在「方法與來源」查看，照片無法載入時保留姓名與中性缺圖標記。放大後從表格選到畫面外的資料點時，保持倍率並平移至該點；點已可見時不移動，圖上點選與下方選單也不自動平移。選中點持續顯示於其他民調與官方紅星上方，直到換選或取消選取。排序相同點位保留範圍；切換選舉或改變圖中資料集合時重設。

首次載入與切換選舉不預選民調；兩人及三人圖仍顯示全部可繪製點、官方結果與背景區域，沒有可計算民調時保留官方結果。選取表格、圖上圓點或圖表選單可查看計算詳情；點頁面空白或圖表底色會取消選取，保留目前縮放與位置。來源連結、詳情文字、篩選控制、滾輪與拖曳不觸發取消。排序或篩選後仍可見的選取紀錄會保留；被排除則清除，撤回篩選不自動恢復。窄版初次不開啟詳情視窗，點外側遮罩取消選取並關閉；視窗內點圖表底色只取消選取。鍵盤焦點與正常操作不受取消選取影響。

## 開發與驗證

```text
npm ci
npm test
npm run build
npm run test:sites
npm run check:bundle
```

React／Vite 前端，Plotly 圖表，保留 Product Design 的 Sites Worker 與 build 契約。`dist/client` 是公開靜態內容，`dist/server/index.js` 是 Worker，`dist/.openai/hosting.json` 是部署設定。沒有帳號、留言、自動蒐集、密鑰、D1 或 R2 需求。

tests/fixtures.mjs 僅供隔離的單元測試，網站沒有載入，也不包含在 dist。來源倉庫以 allowlist 排除內部報告、私人對話、參考圖片、裝置資料與本機工作檔。
