# 台灣選情劉伯溫

[開啟網站：taiwan-election-liubowen.papple23g.com](https://taiwan-election-liubowen.papple23g.com)

把台灣已公布的民調和官方選舉結果放在一起，看看民調與開票結果差多少，也能比較各機構在歷次選舉中的表現。尚未投票的選舉只整理民調，不預測結果或勝率。

## 怎麼使用

- 選擇一場選舉，切換各機構的最新民調與「歷史」調查。
- 點選圖表或表格中的民調，可以對照另一邊的位置；點「詳情」查看來源與查核紀錄。
- 使用機構和時間篩選，或到「跨場比較」查看各機構的平均誤差與逐場結果。

## 誤差代表什麼

平均絕對誤差（MAE）的單位是百分點，越小代表民調越接近該場結果。計算時先將同一組候選人的民調支持度和官方票數各自換算為合計 100%，再平均各候選人的差距，不分正負。例如民調為 55% / 45%、結果為 50% / 50%，誤差就是 5 個百分點。

跨場比較每品牌每場採計一份封關／最新的可計算民調，再按該品牌自身場次的 MAE 等權平均。各品牌採計的選舉可能不同，排序不代表同條件的機構可信度排名。跨場預設勾選「選前30天」及「採計至少 5 場」，兩項都可取消；5 場是顯示門檻，不保證比較結果穩定。單場的「選前 30 天」預設關閉。

## 資料與限制

本站未收錄所有民調，部分資料仍待核實。有公開來源且能與已核實官方結果對照計算的待核實紀錄，也可能採計跨場平均；可以計算或納入平均都不代表來源已核實，採計不會改變查核狀態。缺漏與衝突可在「詳情」查看，缺值不補零，未表態不分配給候選人。本站是個人製作的資料整理工具，不代表官方立場，也不提供投票建議。

完整方法、資料來源和照片授權可在網站的「方法與來源」查看。也可以下載[民調與選舉資料](public/data/verified.json)及[來源與查核紀錄](public/data/verified-source.json)；資料欄位與重建方式見[資料契約](DATA-CONTRACT.md)。

## 本機執行

需要 Node.js 和 npm：

~~~powershell
npm ci
npm run dev
~~~

開啟 [http://localhost:26298](http://localhost:26298)。開發服務監聽所有網路介面的 `0.0.0.0:26298`；埠已被占用時會停止啟動。

檢查與建置：

~~~powershell
npm run build
npm run check:bundle
~~~
